# 제1고지: 미분 자동 계산
## 01.0 무(Zero)에서 시작하여 자동 미분의 엔진을 완성하다

제1고지에서는 딥러닝 프레임워크의 가장 핵심적인 심장인 **자동 미분(Automatic Differentiation)** 시스템을 밑바닥부터 직접 만듭니다.  
단 3줄의 파이썬 코드로 데이터를 담는 상자(`Variable`)를 정의하는 것에서 출발하여, 연산을 수행하는 함수(`Function`), 계산 그래프(DAG)의 동적 연결, 그리고 연쇄 법칙(Chain Rule)에 기반한 **오차역전파법(Backpropagation)의 자동화**와 자동 단위 테스트까지 단계별로 정복합니다.

![01 미분 자동 계산](./01_미분_자동_계산.png)
**그림 01-Intro** 단 3줄의 Variable 클래스에서 출발하여 계산 그래프와 자동 역전파(Backpropagation) 엔진을 완성하는 여정 (이호진 교수와 도로시 탐험대)

> 제1고지 미분 자동 계산의 첫 관문에 들어섰습니다. 현대 딥러닝의 거대한 성채는 복잡한 수식의 숲처럼 보이지만, 그 심장부를 열어보면 아주 단순한 데이터 상자와 연산 장치의 연결로 이루어져 있습니다. 우리는 복잡한 프레임워크의 블랙박스를 걷어내고, 단 세 줄의 변수 상자 정의에서 출발하여 스스로 미분을 수행하는 역전파 엔진을 한 땀 한 땀 조립해 나갈 것입니다. 화면의 일러스트처럼 지니와 도로시 탐험대와 함께 기초 수학과 코드로 자동 미분의 본질을 완벽히 정복해 봅시다.

단 3줄의 Variable 상자에서 출발하여 계산 그래프와 자동 역전파 엔진의 기초를 완성했습니다.  
다음 제2고지에서는 다중 입출력과 자연스러운 연산자 오버로딩의 세계로 나아갑니다.

**질의응답(Q&A) 및 토론**

> 제1고지 미분 자동 계산의 대장정을 성공적으로 완주하셨습니다. 우리는 가장 밑바닥인 세 줄의 변수 상자 정의에서 출발하여, 스스로 계산 그래프를 추적하고 연쇄 법칙을 따라 기울기를 역전파하는 자동 미분 엔진의 근본 원리를 코드와 수학으로 증명해 냈다. 이 탄탄한 기초 위에서 다음 제2고지에서는 여러 입출력을 다루고 덧셈과 곱셈 연산자를 자연스럽게 코딩하는 진정한 딥러닝 프레임워크의 모습을 완성해 나가겠습니다.
