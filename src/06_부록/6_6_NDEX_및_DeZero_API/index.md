# 이번엔 프레임워크다! 손으로 배우는 본격 딥러닝 학습서

## Deep Learning from Scratch 3

이 교제는 '밑바닥부터' 직접 만들어보며 즐겁게 딥러닝을 익힐 수 있는 시리즈의 장점을 그대로 따랐습니다. DeZero라는 딥러닝 프레임워크를 단계별로 차근차근 구현하다 보면 어느새 프레임워크 기본 지식을 익히게 됩니다. 딥러닝과 파이썬 지식을 어느 정도 갖췄다면 전편을 읽지 않았더라도 충분히 따라올 수 있습니다.

* **제1고지** 프레임워크 개발을 위한 기반을 마련합니다.
* **제2고지** 프레임워크를 사용하는 코드가 더 자연스럽게 보이도록 합니다.
* **제3고지** 2차 미분을 구할 수 있도록 프레임워크를 확장합니다. '역전파의 역전파' 구조를 배우고 이해하면 프레임워크의 새로운 가능성에 눈을 뜨게 됩니다.
* **제4고지** 프레임워크를 신경망용으로 정비하고 이를 사용해 손쉽게 신경망을 구축합니다.
* **제5고지** CPU 대응, 모델 저장과 복원 등 실전 딥러닝에 꼭 필요한 기능을 추가합니다. CNN, RNN 등 발전된 모델도 다룹니다. 딥러닝 응용을 다루는 이 주제들을 프레임워크로 구현한다면 간단한 코드만으로 해결할 수 있습니다.

---

> 이 교제로 딥러닝 프레임워크에 대한 기본 구조를 이해하고 나면 텐서플로와 파이토치 같은 프레임워크 코드를 직접 보는 것도 한결 수월해질 것입니다. 딥러닝뿐만 아니라 머신러닝, 인공지능에 관심 있는 파이썬 엔지니어에게는 꼭 추천하고 싶습니다.
