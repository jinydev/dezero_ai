00. 프롤로그

프롤로그

DeZero 프레임워크의 탄생 배경, 지은이·옮긴이 소개, 추천사와 딥러닝 프레임워크를 밑바닥부터 만드는 여정을 시작합니다.

프롤로그 보기 ➔
01. 제1고지

미분 자동 계산

상자로서의 변수와 함수를 구현하고, 수치 미분의 한계를 극복하는 역전파 이론과 계산 그래프의 역전파 자동화를 완성합니다 (1~10단계).

제1고지 시작 ➔
02. 제2고지

자연스러운 코드로

가변 길이 입출력 함수, 연산자 오버로드(+, *, -, /), 메모리 관리와 순환 참조를 해결하여 진짜 파이썬다운 코드로 진화합니다 (11~24단계).

제2고지 탐구 ➔
03. 제3고지

고차 미분 계산

계산 그래프 시각화(Graphviz DOT), 테일러 급수와 뉴턴 방법 최적화, 역전파의 계산 그래프를 만드는 고차 미분을 구현합니다 (25~36단계).

제3고지 정복 ➔
04. 제4고지

신경망 만들기

다차원 텐서, Linear 계층, 활성화 함수, Optimizer, DataLoader를 완성하고 실제 MNIST 손글씨 숫자를 분류 학습합니다 (37~51단계).

제4고지 구축 ➔
05. 제5고지

DeZero의 도전

CuPy를 통한 GPU 가속, 모델 저장/로드, CNN 합성곱 신경망(VGG16), 시계열 데이터를 다루는 RNN/LSTM까지 최신 딥러닝을 구현합니다 (52~60단계).

제5고지 도전 ➔
06. 부록

부록 및 API

인플레이스 연산의 비밀, 슬라이스 get_item 구현, Google Colab 실행 가이드, 참고문헌 및 DeZero 전체 API 사전을 제공합니다.
