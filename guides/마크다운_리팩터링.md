# 강의 교재 마크다운 문서 품질 개선 및 리팩터링 가이드

본 문서는 강의 및 교재용 마크다운(`.md`) 문서를 작성하거나 OCR/북스캔으로 변환한 후, **타이포라(Typora), 옵시디언(Obsidian), VS Code, 깃허브(GitHub)** 등 다양한 마크다운 뷰어에서 수식과 이미지가 깨짐 없이 완벽하게 렌더링되도록 검수하고 교정하기 위한 표준 가이드라인입니다.

## 1. 인라인 수식(Inline Math) 렌더링 가이드

### 1.1 타이포라 뷰어 환경설정 (필수 사전 작업)
* **문제 현상**: 타이포라에서 독립 줄의 블록 수식(`$$ ... $$`)은 잘 나오는데, 본문 문장 속 인라인 수식(`$\frac{dy}{dy}$`, `$x$`)만 코드 그대로 노출됨.
* **원인**: 타이포라는 초기 설치 시 화폐 기호(`$100`) 오인식을 방지하기 위해 **인라인 수식 기능이 기본 비활성화(`enable_inline_math = 0`)**되어 있습니다.
* **해결 방법**:
  1. **Typora GUI 설정**: `Cmd + ,` (환경설정) $\rightarrow$ `마크다운 (Markdown)` $\rightarrow$ `마크다운 문법 지원` $\rightarrow$ **`인라인 수학공식 (Inline Math)`** 체크 후 타이포라 재시작.
  2. **macOS 터미널 명령 (즉시 적용)**:
     ```bash
     defaults write abnerworks.Typora enable_inline_math -bool true
     ```
     *(적용 후 실행 중인 Typora를 `Cmd + Q`로 완전히 종료 후 재실행)*

---

### 1.2 수식 뒤 한글 조사 결합 시 공백 확보 (핵심 문법 규칙)
* **문제 현상**: 뷰어의 인라인 수식 옵션을 켰음에도 `$\frac{dy}{dy}$는`, `$\frac{dy}{dx}$를`, `$y$의` 처럼 적힌 곳이 여전히 렌더링되지 않고 텍스트로 보임.
* **원인**: CommonMark 및 MathJax/KaTeX 파서는 닫는 `$` 바로 뒤에 단어 문자(한글 음절 `가-힣`, 알파벳, 숫자)가 공백 없이 붙어 있으면 수식 종료 기호로 인식하지 않고 일반 문자열로 취급합니다.
* **표준 작성 원칙**: **닫는 `$` 기호와 뒤따르는 한글 조사 사이에는 반드시 공백 1칸을 둡니다.**

| 잘못된 작성 (수식 깨짐) | 올바른 작성 (완벽 렌더링) | 렌더링 결과 |
| :--- | :--- | :--- |
| `$\frac{dy}{dy}$는 항상 1입니다.` | `$\frac{dy}{dy}$ 는 항상 1입니다.` | $\frac{dy}{dy}$ 는 항상 1입니다. |
| `최종적으로 $\frac{dy}{dx}$가 구해집니다.` | `최종적으로 $\frac{dy}{dx}$ 가 구해집니다.` | 최종적으로 $\frac{dy}{dx}$ 가 구해집니다. |
| `$y$의 각 변수에 대한 미분값` | `$y$ 의 각 변수에 대한 미분값` | $y$ 의 각 변수에 대한 미분값 |
| `함수 $y = C(b)$의 도함수` | `함수 $y = C(b)$ 의 도함수` | 함수 $y = C(b)$ 의 도함수 |
| `$B'(a)$이고 $A'(x)$입니다.` | `$B'(a)$ 이고 $A'(x)$ 입니다.` | $B'(a)$ 이고 $A'(x)$ 입니다. |

> [!TIP]
> **수식 안쪽 공백 주의**:
> * 올바름: `$\frac{dy}{dx}$` (안쪽에 공백 없음)
> * 잘못됨: `$ \frac{dy}{dx} $` (`$` 안쪽에 공백이 있으면 인라인 수식 파싱 실패)

## 2. 블록 수식(Display Math) 작성 표준

독립된 줄로 강조되는 핵심 공식은 블록 수식(`$$`)을 사용합니다.

```markdown
$$
\frac{dy}{dx} = \frac{dy}{dy} \frac{dy}{db} \frac{db}{da} \frac{da}{dx}
$$

[식 5.2]
```

1. 시작 `$$`와 끝 `$$`는 반드시 **독립된 빈 줄**에 배치합니다.
2. 수식 번호(예: `[식 5.2]`)는 수식 블록 아래 줄에 불필요한 공백 없이 단독 줄로 표기하거나, KaTeX 표준 `\tag{식 5.2}`를 수식 내부에 사용합니다.

## 3. 이미지 상대 경로(Relative Path) 검증

* **문제 현상**: 서브챕터 마크다운에서 이미지가 엑박(Broken Link)으로 나타남.
* **원인**: 서브폴더 구조화 시 이미지가 해당 챕터의 로컬 `./img/`에 있음에도 예전 상위 경로인 `../img/`로 링크되어 있는 경우.
* **표준 경로 규칙**:
  * 각 서브챕터 폴더 구조:
    ```text
    1_5_역전파_이론/
    ├── img/
    │   ├── fig-1337.jpg
    │   └── fig-1339-1.jpg
    └── index.md
    ```
  * 마크다운 내 이미지 링크:
    * ❌ 잘못됨: `![그림 5-2](../img/fig-1339-1.jpg)`
    * ⭕ 올바름: `![그림 5-2](./img/fig-1339-1.jpg)`
* **다중 그림 분기 원칙**: 한 페이지에 그림이 여러 개 매핑되는 경우 반드시 `fig-xxx-1.jpg`, `fig-xxx-2.jpg` 형태로 물리 분기하여 각각의 이미지 태그를 독립 생성합니다.

## 4. 문서 구조 및 타이포그래피 정제

### 4.1 마크다운 헤더 계층 일관성
OCR 변환본에서 누락되기 쉬운 소제목을 올바른 마크다운 헤더(`##`, `###`)로 승격합니다.
* ❌ `5.2 역전파 원리 도출` (단순 텍스트)
* ⭕ `## 5.2 역전파 원리 도출` (H2 헤더)

### 4.2 주석 / 주의사항(Callout) 블록화
단순 텍스트 접두어(`NOTE_`, `CAUTION_`, `WARNING_`)를 마크다운 표준 인용 블록으로 변환하여 시각적 가독성을 높입니다.
```markdown
> **NOTE**  
> $\frac{dy}{dy}$ 는 $y$ 의 $y$ 에 대한 미분입니다. 이때 $y$ 가 작은 값만큼 변하면...
```

### 4.3 줄바꿈 오류 및 오탈자 정제
OCR 문장 결합 과정에서 잘못 분리된 단어를 연결합니다.
* ❌ `x와 $\frac{dy}{dx}$가 대응합니다. 또` / `한 함수에도 대응 관계가 보입니다.`
* ⭕ `$x$ 와 $\frac{dy}{dx}$ 가 대응합니다. 또한 함수에도 대응 관계가 보입니다.`

### 4.4 문맥 단위 블록화 (`---`)
* 맥락과 설명 단위가 바뀌는 지점에 `---` 수평선을 배치하여 설명 단위를 블록화합니다.
* 각 블록에는 향후 캐릭터 일러스트를 삽입할 수 있도록 빈 이미지 링크 `![]()`를 미리 배치합니다.

## 5. 일괄 검사 및 자동 수정 스크립트

터미널에서 아래 Python 원라이너 및 스크립트를 사용하여 폴더 내 모든 마크다운 문서의 수식 공백 및 이미지 경로 문제를 일괄 검사·수정할 수 있습니다.

### 5.1 수식-조사 결합 일괄 자동 교정 스크립트
```python
import glob, re

# 대상 폴더 지정
files = sorted(glob.glob("./src/**/*.md", recursive=True))
p = re.compile(r"\$([^\$\n]+)\$([가-힣])")

total_fixed = 0
for path in files:
    with open(path, "r", encoding="utf-8") as f:
        content = f.read()
    new_content, count = p.subn(r"$\1$ \2", content)
    if count > 0:
        with open(path, "w", encoding="utf-8") as f:
            f.write(new_content)
        total_fixed += count
        print(f"[{path}] {count}개 수식 공백 자동 보정 완료")

print(f"총 {total_fixed}개 수식 교정 완료!")
```

### 5.2 상대 이미지 경로(`../img` -> `./img`) 자동 교정 스크립트
```python
import glob, re

files = sorted(glob.glob("./src/**/index.md", recursive=True))
img_p = re.compile(r"!\[(.*?)\]\(\.\./img/([^)]+)\)")

for path in files:
    with open(path, "r", encoding="utf-8") as f:
        content = f.read()
    new_content, count = img_p.subn(r"![\1](./img/\2)", content)
    if count > 0:
        with open(path, "w", encoding="utf-8") as f:
            f.write(new_content)
        print(f"[{path}] {count}개 이미지 경로 보정 완료")
```

## 6. 최종 점검 체크리스트 (Checklist)

문서 편집 또는 리팩터링 완료 후 다음 항목을 점검합니다:

- [ ] **타이포라 인라인 수식 옵션 활성화 여부 확인** (`enable_inline_math = 1`)
- [ ] **문장 내 수식 뒤 공백 확인** (`$math$ 조사` 형태로 띄어쓰기 적용 여부)
- [ ] **수식 태그 짝 일치 여부** (문서 전체 `$` 기호 개수가 짝수인지 확인)
- [ ] **이미지 상대 경로 정상 여부** (`./img/` 폴더 내 실제 파일 존재 및 연결 확인)
- [ ] **헤더 넘버링 및 마크다운 태그 정상화** (`## 1.1`, `## 1.2` 등)
- [ ] **NOTE / CAUTION 인용 블록화** (`> **NOTE**`)
- [ ] **설명 단위별 `---` 구분선 및 `![]()` 삽입 여부**
